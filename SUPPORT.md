# Support

## Before opening a report

Run `npm run check`, then read the troubleshooting and compatibility sections. Search [existing issues](https://github.com/hudhaifahz/nostr-signer-chatgpt/issues)
for the exact error, browser, signer, and version.

## Bug and compatibility reports

Include the OS, Node version, AI host, browser, signer and version, connection method, relevant relay
URLs, expected behavior, actual behavior, and redacted logs. State whether the result was simulated or
live. Never include a private key, seed phrase, pairing URI, token, private-message plaintext, or real
account identifier.

## Security reports

Do not file exploitable security details in a public issue. Use the repository's
[private vulnerability report](https://github.com/hudhaifahz/nostr-signer-chatgpt/security/advisories/new)
and follow `SECURITY.md`.

## Current support level

This is a community public-beta candidate. There is no guaranteed response time or service-level
agreement. The release owner must replace this paragraph with a maintained public support URL and
contact before marketplace submission.
